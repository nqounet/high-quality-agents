# AGENTS.md

## プロジェクト概要

このリポジトリは、AGENTS.md フォーマットのデモンストレーションです。AGENTS.md は、AI コーディングエージェントがプロジェクトで効果的に作業するために必要なコンテキストと指示を提供するためのオープンな仕様です。AGENTS.md フォーマットは、自動化ツール向けの詳細な技術的コンテキストを含むことで README.md を補完するよう設計されています。

**主要技術**: Markdown

**目的**: https://agents.md/ の公開ガイダンスに従った、適切に構造化された AGENTS.md ファイルのリファレンス実装および例として機能すること。

## セットアップコマンド

これはドキュメント中心のリポジトリのため、ビルドやインストール手順は必要ありません:

- リポジトリのクローン: `git clone <repository-url>`
- プロジェクトルートへ移動: `cd <project-directory>`

## 開発ワークフロー

このリポジトリにはドキュメントファイルのみが含まれています。コントリビュートするには:

1. `main` から新しいブランチを作成する
2. Markdown ファイルを変更する
3. Markdown の構文とフォーマットを検証する
4. プルリクエストを送信する

## テスト手順

Markdown のみのリポジトリの場合:

- Markdown リンクの検証: すべてのリンクが正しく解決されることを確認する
- Markdown 構文の検証: `npx markdownlint-cli2 "**/*.md"`
- レンダリング出力の確認: エディタまたはブラウザで Markdown ファイルをプレビューする

## コードスタイル

### Markdown ガイドライン

- ATX スタイルの見出しを使用する（`#` 記号）
- 言語識別子付きのフェンスドコードブロックを使用する
- 一貫したリストフォーマットを維持する（順序なしリストには `-` を使用）
- 読みやすさのためにセクション間に空行を入れる
- 生の URL ではなく意味のあるリンクテキストを使用する
- 読みやすさのために適度な行の長さを維持する

### ファイル構成

- AGENTS.md をリポジトリルートに配置する
- 明確で説明的なセクション見出しを使用する
- セクションを重要度の高い順に並べる
- 関連する情報をグループ化する

## ビルドとデプロイ

このドキュメントリポジトリにはビルドやデプロイの手順は必要ありません。`main` ブランチにマージされた変更はすぐに利用可能になります。

## プルリクエストガイドライン

- **タイトル形式**: `[docs] 変更の簡潔な説明`
- **必須チェック**: 送信前に Markdown 構文を検証する
- **レビュー要件**: すべてのセクションが正確で実行可能であることを確認する
- **コミットメッセージ**: 明確で説明的なコミットメッセージを使用する

- Aider

- その他多数

### AGENTS.md ファイル作成のベストプラクティス

1. **具体的に**: 曖昧な説明ではなく、正確なコマンドを含める
2. **コードブロックを使用**: コマンドはバッククォートで囲んで明確にする
3. **コンテキストを含める**: 特定の手順が必要な理由を説明する
4. **最新の状態を維持**: プロジェクトの進化に合わせて更新する
5. **コマンドをテスト**: 記載されたすべてのコマンドが実際に動作することを確認する
6. **ネストされたファイルを検討**: モノレポの場合、サブプロジェクトにも AGENTS.md ファイルを作成する

### このテンプレートの適用

このテンプレートを自分のプロジェクトに使用する場合:

1. プレースホルダーセクションをプロジェクト固有のコマンドに置き換える
2. 言語固有のコードスタイルガイドラインを追加する
